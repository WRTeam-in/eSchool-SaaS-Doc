# Template

School admins can create templates for certificates as per the requirements.

![e-School SaaS](../../static/images/schooladmin/list-template.png)

School admins can create new templates with drag and drop builder and fully customizable with different fields like student name, class, roll number, date, etc.

![e-School SaaS](../../static/images/schooladmin/create-template.png)
