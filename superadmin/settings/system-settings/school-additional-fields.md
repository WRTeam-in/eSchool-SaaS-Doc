# School Additional Fields

## Overview
Define custom fields that schools can fill out during registration or update in their profiles.

## Key Features
- Dynamic field creation
- Support for different field types (text, dropdown, checkbox)
- Mandatory/Optional configuration

## Usage Instructions
1. Navigate to **Settings** > **System Settings** > **School Additional Fields**.
2. Add new fields or manage existing ones.
3. These fields will appear in the school management and registration forms.
