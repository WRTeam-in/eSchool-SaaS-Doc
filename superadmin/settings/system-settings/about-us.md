# About Us

![e-School SaaS](../../../static/images/superadmin/about-us.png)

## Overview
Configure the "About Us" content for the front site to provide information about the school system.

## Key Features
- Rich text editor for content
- Image management
- Vision and Mission sections

## Usage Instructions
1. Navigate to **Settings** > **System Settings** > **About Us**.
2. Compose your content using the editor.
3. Save to publish changes.
